# 일과 기록

메모장에 매일 적던 일과(공부 시간, 수면, 아침 물 한 잔 등)를 탭 몇 번으로 기록하는 개인용 앱. 아이폰 홈 화면에 추가해서 사용.

## 기능

- 반복 항목 버튼: 한 번 등록해 두고 탭만 하면 기록 (기본: 수면, CCNA 공부, 따뜻한 물, 운동)
- 항목 종류 두 가지
  - 시간 기록형: 탭하면 시작, 다시 탭하면 끝 → "몇 시~몇 시"가 자동 기록
  - 한 번 체크형: 탭하면 그 시각이 기록
- 진행 중인 타이머는 앱을 닫아도 유지 (잠 같은 자정 넘기는 기록도 가능)
- 시간 직접 입력: 시각 휠로 선택, "지금" 버튼, 길이 버튼(15분~2시간)으로 시작/끝 자동 계산
- 끝이 시작보다 빠르면 다음 날로 계산 (잠 23:30 → 06:45 = 7시간 15분)
- 날짜 이동(‹ ›, 날짜 눌러서 달력), 기록 탭하면 수정, 왼쪽으로 밀면 삭제(되돌리기 가능)
- 메모장용 글: 하루 기록을 텍스트로 만들어 "복사" 한 번으로 메모장에 붙여넣기
- 통계: 최근 7일/30일 항목별 합계와 일별 막대
- 설정: 항목 추가/수정/삭제/순서 변경, 백업 내보내기/가져오기
- 다크모드, 홈 화면 앱(safe-area, 큰 터치 영역)

## 구조

- React 18 + create-react-app (FORGE, 설교 노트와 같은 방식)
- `src/App.jsx` 앱 전체, `src/App.css` 스타일
- 데이터는 localStorage의 `dailylog:v1` 하나에 저장 (서버·DB 없음)
- 시각은 `YYYY-MM-DDTHH:MM` 현지 시간 문자열로 저장
- 불러올 때 항목/기록을 자동 정리(normalize). 읽을 수 없는 데이터는 지우지 않고 `dailylog:v1:corrupt-...` 키에 따로 보관
- 배포: GitHub main에 push → Vercel 자동 배포 (무료)

## 알려진 한계

- 기록은 기기 localStorage에만 저장 → 가끔 백업 내보내기
- Safari에서 쓴 데이터와 홈 화면 앱 데이터는 서로 따로 → 홈 화면 아이콘 앱만 사용
- 자정을 넘긴 기록은 시작한 날의 합계/통계에 들어가고, 끝나는 날 화면에는 "전날부터"로 같이 표시
- 항목 종류(시간 기록/한 번 체크)는 만든 뒤 바꿀 수 없음
- 백업 내보내기는 아이폰에서 공유 시트(파일에 저장)로 열리는 방식이라 실제 폰 확인이 필요
