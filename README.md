# 일과 기록

메모장에 매일 적던 일과(공부 시간, 수면, 아침 물 한 잔 등)를 탭 몇 번으로 기록하는 개인용 앱. 아이폰 홈 화면에 추가해서 사용.

## 기능

- 반복 항목 버튼: 한 번 등록해 두고 탭만 하면 기록 (기본: 수면, CCNA 공부, 따뜻한 물, 운동)
- 항목 종류 두 가지
  - 시간 기록형: 탭하면 시작, 다시 탭하면 끝 → "몇 시~몇 시"가 자동 기록
  - 한 번 체크형: 탭하면 그 시각이 기록
- 진행 중인 타이머는 앱을 닫아도 유지 (잠 같은 자정 넘기는 기록도 가능)
- 기록 추가(메모장처럼 자세히): 시작 시각이 직전 기록이 끝난 시각으로 자동 입력(이어서 기록), 끝은 지금, 여러 줄 내용칸, "빠른 문구" 탭으로 자주 쓰는 말 입력, 항목은 선택(없어도 됨)
- 시간 직접 입력: 시각 휠로 선택, "지금" 버튼, 길이 버튼(15분~2시간)으로 시작/끝 자동 계산
- 대략 적기: 시각을 모를 때 기록 추가 화면에서 "대략 · 시간 모름"을 고르면 시간대(하루종일/새벽/오전/오후/저녁/밤)와 내용만 적음. 길이 계산·통계에 안 들어가고 "하루 요약"에 따로 모이며, 메모장용 글에는 `(오후) 내용` 문장으로 들어감. 수면처럼 정확히 기억나는 건 따로 정확한 시각으로 적어서 통계 유지
- 하루 일기: 날짜마다 자유롭게 쓰는 칸, 메모장용 글 끝에 같이 붙음
- 아이콘: 이모지 80여 개 + 이모지 키보드로 직접 입력
- 폰↔아이패드 동기화: 같은 "동기화 암호"로 연결하면 자동으로 맞춰짐 (아래 "동기화" 참고)
- 끝이 시작보다 빠르면 다음 날로 계산 (잠 23:30 → 06:45 = 7시간 15분)
- 날짜 이동(‹ ›, 날짜 눌러서 달력), 기록 탭하면 수정, 왼쪽으로 밀면 삭제(되돌리기 가능)
- 메모장용 글: 하루 기록을 메모장과 같은 모양(`6:00 - 8:00 내용`)으로 만들어 "복사" 한 번으로 붙여넣기
- 통계: 최근 7일/30일 항목별 합계와 일별 막대
- 설정: 항목 추가/수정/삭제/순서 변경, 백업 내보내기/가져오기
- 오늘 화면 위쪽 항목을 자유롭게 편집: 오른쪽 위 "편집" → ✕로 삭제(되돌리기 가능), ◀▶로 순서, 탭하면 수정, "새 항목"으로 추가
- 항목을 길게 누르면 아이폰 홈 화면처럼 흔들리며 ✕가 나오는 편집 모드가 켜짐("편집" 버튼으로도 가능, "완료"로 끝냄). 설정에서 "동작 줄이기"를 켜 두면 흔들림은 멈춤
- 항목 그룹: 그룹마다 이름(예: "자주 쓰는 단어들")을 붙이고, 추가/이름 바꾸기/순서/삭제, 항목을 다른 그룹으로 옮기기
- 기본 언어(한국어/English): 설정에서 고르면 이 기기에 저장되어 다음에 열 때도 그대로
- 디자인 3종: 우드 노트(기본), 핑크, 시크 다크 — 설정에서 선택, 이 기기에 저장
- 홈 화면 앱(safe-area, 큰 터치 영역)

## 구조

- React 18 + create-react-app (FORGE, 설교 노트와 같은 방식)
- `src/App.jsx` 앱 전체, `src/i18n.js` 한국어/영어 글자, `src/App.css` 스타일(테마별 CSS 변수)
- `api/sync.js` 동기화 서버(Vercel 서버리스 함수), 저장소는 Upstash Redis
- 기기 안 저장: localStorage의 `dailylog:v1` (구조 버전 3, 그룹 추가). 인터넷이 없어도 항상 먼저 여기에 저장
- 시각은 `YYYY-MM-DDTHH:MM` 현지 시간 문자열로 저장
- 항목·기록·문구·일기마다 수정 시각 `u`가 있고, 삭제는 `gone`에 기록으로 남김
- 불러올 때 자동 정리(normalize): v1 기록(수정 시각·순서 없음)도 그대로 읽어서 v2로 변환. 읽을 수 없는 데이터는 지우지 않고 `dailylog:v1:corrupt-...` 키에 따로 보관
- 언어·디자인 설정: `dailylog:prefs` ({lang, theme}), 기기별이라 동기화/백업에 안 들어감. 화면이 뜨기 전에 `public/index.html`의 작은 스크립트가 테마를 먼저 적용
- 배포: GitHub main에 push → Vercel 자동 배포 (무료)

## 동기화

- 방식: 항목 하나하나의 수정 시각 `u`를 비교해서 더 늦게 고친 쪽이 이김. 서버는 쓸 때마다 번호(s)를 매기고, 기기는 "마지막으로 받은 번호 이후"만 받아감. 삭제도 전달됨
- 시점: 앱을 열 때, 화면으로 돌아올 때, 인터넷이 돌아올 때, 90초마다, 고친 뒤 1.5초 뒤
- 서버 기록이 비워진 걸 알아채면 이 기기의 기록을 전부 다시 올림. 설정의 "처음부터 다시 맞추기"로 수동 복구도 가능
- 인증: 요청 헤더 `x-sync-key`가 환경변수 `SYNC_KEY`와 같아야 함 (로그인 계정 없음)
- 환경변수 (Vercel > Settings > Environment Variables): `SYNC_KEY` 직접 입력, `KV_REST_API_URL`/`KV_REST_API_TOKEN`은 Storage에서 Upstash 연결 시 자동
- 설정이 없으면 앱은 기기 안에서만 정상 동작하고, 설정 화면에 안내가 뜸

## 알려진 한계

- 기록은 기기 localStorage에만 저장 → 가끔 백업 내보내기
- Safari에서 쓴 데이터와 홈 화면 앱 데이터는 서로 따로 → 홈 화면 아이콘 앱만 사용
- 자정을 넘긴 기록은 시작한 날의 합계/통계에 들어가고, 끝나는 날 화면에는 "전날부터"로 같이 표시
- 항목 종류(시간 기록/한 번 체크)는 만든 뒤 바꿀 수 없음
- 영어로 바꿔도 직접 만든 항목/그룹 이름은 번역되지 않음(기본으로 들어 있는 이름만 번역, 이름을 직접 고친 건 그대로)
- 우드 노트 제목 글꼴(Noto Serif KR)은 Google Fonts에서 불러옴 → 인터넷이 없으면 기본 글꼴로 보임
- 시크 다크에서 아이폰 맨 위 상태바 모양은 실제 폰 확인 필요
- 백업 내보내기는 아이폰에서 공유 시트(파일에 저장)로 열리는 방식이라 실제 폰 확인이 필요
- 동기화는 모의 Redis로만 시험했고, 실제 Upstash와는 배포 후 확인 필요
- 두 기기가 같은 순간에 같은 기록을 고치면 나중에 고친 쪽이 이김(앞선 수정은 사라짐). 서로 다른 기록은 모두 보존
- 기기 시계가 크게 틀리면 수정 시각 비교가 어긋남
- Upstash 무료 DB가 오래 안 쓰이면 비워질 수 있음 → 기기에 기록이 남아 있어서 자동으로 다시 올라감. 그래도 가끔 백업
- 동기화 암호는 기기의 localStorage에 저장됨(백업 파일에는 안 들어감)
- 아이폰 홈 화면 앱에서 내용칸 자동 커서와 키보드 유지는 실제 폰 확인 필요
